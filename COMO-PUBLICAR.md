# Como publicar o site (grátis, sem mensalidade)

## Passo 1 — Preencha o que falta
Abra `index.html` num editor de texto (ou peça pra mim editar) e troque:
- Os links de vídeo (seção "Sets & Vídeos" e "Quimera Estúdio IA")
- WhatsApp, Instagram e e-mail no rodapé (procure por `SEUNUMEROAQUI`, `SEUUSUARIOAQUI`, `seuemail@exemplo.com`)
- O texto de bio na seção "O Som", se quiser algo mais pessoal

## Passo 2 — Publicar de graça (escolha uma opção)

### Opção mais simples: Netlify Drop
1. Acesse https://app.netlify.com/drop
2. Arraste a pasta `site-dj-alef` inteira pra dentro da página
3. Pronto — você recebe um link tipo `nome-aleatorio.netlify.app` na hora, sem criar conta pra testar

### Opção mais durável: GitHub Pages
1. Crie uma conta grátis em https://github.com (se ainda não tiver)
2. Crie um repositório novo, público, e suba o arquivo `index.html`
3. Em Settings → Pages, ative o GitHub Pages apontando pra branch principal
4. Seu site fica em `seuusuario.github.io/nome-do-repositorio`

## Passo 3 — Domínio próprio (só depois, quando fizer sentido)
Um domínio tipo `djalef.com.br` custa por volta de R$40/ano (Registro.br). Não é necessário agora — o link grátis do Netlify ou GitHub Pages já funciona pra divulgar. Deixe essa compra pra quando o site já estiver trazendo retorno, conforme o teto de gastos que você já definiu na parte financeira.
